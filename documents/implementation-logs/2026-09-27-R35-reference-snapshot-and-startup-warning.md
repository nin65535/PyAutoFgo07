# R35 実装ログ — 参照スナップショットと同時起動警告

- 実施日: 2026-09-27
- 対象: R35「再生開始時の参照スナップショット、両アプリの同時起動警告、実環境確認」
- 状態: 完了

## 実施内容

### フロントエンド

- プレイヤーとサンプラーの後起動側に、10秒間表示される同時起動警告を追加した。手動でも閉じられる。
- サンプラーの9候補を切り出し位置に対応する3×3配置へ変更し、標準位置を中央に置いた。

### バックエンド

- プレイヤーのAll/Wave開始時に承認済み参照manifestとPNGを読み込み、再生中のカード判定器を固定した。次の再生開始時に読み直す。
- 起動時に相手アプリのローカルポートを確認し、後起動側の画面へ検知結果を渡すAPIを追加した。
- プレイヤーのAPIを静的ファイルの全パス配信より先に登録し、警告APIが正しく応答するよう修正した。

### プロジェクト共通

- サンプラーのダブルクリック起動ファイルとPowerShell起動スクリプトを追加し、運用手順を更新した。
- `documents/roadmap.md` のR35を完了にした。

## 検証結果

- バックエンドpytest: 145件成功。Ruff lint・format check: 成功。
- フロントエンド: 本番ビルド、ESLint、Vitest 64件、TypeScriptコンパイル成功。サンプラーJavaScript構文確認成功。
- 本番ビルド配信設定で警告APIの認証済み応答を確認した。
- ユーザーによる実環境確認: サンプラー登録のキャストリア、LA、ダ・ヴィンチを使い、`20 ひき逃げ+.json` が最後までエラーなく進行した。両方の起動順で後起動側の警告表示を確認した。サンプラー終了・再起動後も登録済み参照を正常に参照できた。

## 補足

- 実環境の操作結果はユーザー報告に基づく。自動テストは実際のゲーム画面操作を代替しない。
- 旧アプリには変更を加えていない。

# R14 実装ログ — フロントエンドのシナリオ実行エンジン

- 実施日: 2026-09-22
- 対象: R14「フロントエンドのシナリオ実行エンジンを実装する」
- 状態: 完了

## 実施内容

### フロントエンド

- 検証済みの型付きコマンドを記載順に1件ずつ送信する実行エンジンを追加した。
- UUID v7の指令IDとSSE終端イベントを対応付け、完了通知後にだけ次の命令へ進むようにした。
- 無関係なイベントと重複した終端イベントを無視し、同じ命令の二重送信を防止した。
- 現在位置、完了数、完了通知待ち、停止、送信失敗、指令失敗、30秒のタイムアウトを管理した。
- 一時停止中はタイムアウト計測を止め、再開時に残り時間から継続するようにした。
- 現在のグループ・命令位置と待機状態を実行コントロールへ表示した。

### バックエンド

- 全指令終了後に実行状態を`completed`へ移す`POST /api/commands/complete`を追加した。
- 指令完了SSEの直後、ワーカーが現在指令を解放するまでの短い期間でも完了要求を安全に受け付けるようにした。

### プロジェクト共通

- 実行順序、イベント重複防止、停止、タイムアウトの規則を`documents/design/scenario-execution-engine.md`へ記録した。
- `documents/roadmap.md`のR14を完了へ更新した。

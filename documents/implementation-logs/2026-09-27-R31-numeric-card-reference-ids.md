# R31 実装ログ — カード参照の数値IDと自動採番

- 実施日: 2026-09-27
- 対象: R31「参照データを数値のキャラクターID・衣装IDと自動採番へ移行し、画像名を更新する。プレイヤーとサンプラーが使う検証・保存処理を共通化し、既存参照と判定結果を保つ」
- 状態: 完了

## 実施内容

### バックエンド

- 参照manifestを `schemaVersion: 2` にし、キャラクターID、衣装ID、参照ID、サンプル番号を数値化した。次番号をmanifestへ保存し、削除後も番号を再利用しない。
- `autofgo.card_references` に形式検証、採番、画像名検証、PNGとmanifestの保存を集約した。識別器とCLIが同じ検証を使う。保存失敗時には新規PNGを削除し、元manifestを保つ。
- CLIの参照ID手入力を廃止した。既存衣装には数値 `--appearance-id` を指定し、省略時には新衣装を採番する。
- 旧参照9件を順序を固定して移行し、PNGを `<キャラクター名>-<衣装ID>-<サンプル番号>.png` に改名した。移行スクリプトを `backend/experiments/r31_migrate.py` に残した。
- 回帰fixtureと旧スコア照合ツールを新IDに対応させた。評価用正解manifestは変更していない。

### プロジェクト共通

- [数値ID仕様](../design/r31-card-reference-ids.md)と[現行CLI手順](../card-appearance-registration.md)を更新し、R23設計資料に移行先を明記した。
- ロードマップのR31を完了へ更新した。

## 補足

- 評価用の元戦闘画像はローカルにないため、実画像の全再計算は行っていない。保存済み85枚分の判定fixtureによる判定条件の回帰と、9件の参照PNGバイト同一性を確認した。旧スコアと実画像を照合するツールは新IDの対応へ更新した。
- pytestの通常の一時ディレクトリは実行環境の権限制約で使えず、権限付き環境で作業用ディレクトリを指定して実行した。FastAPI／Starletteの既知の非推奨警告が表示された。

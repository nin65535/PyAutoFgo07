# R19 実装ログ — 実環境での画面配置と自動操作

- 実施日: 2026-09-26
- 対象: R19「実環境で画面配置と自動操作を検証する」
- 状態: 完了

## 実施内容

### バックエンド

- `skill`、`master_skill`、`attack`、`swap` の固定ハンドラーを実画面操作へ接続した。
- LDPlayerのウィンドウ矩形、旧アプリ由来の相対座標、攻撃ボタン画像の一致を用いて操作位置を検証する処理を追加した。
- WindowsのDPI認識をウィンドウ探索時に有効化し、このPCのプライマリ画面で取得画像とクリック座標が一致することを確認した。
- 戦闘画面待機の画像探索では操作ごとのタイムアウトと戦闘待機全体のタイムアウトを分けた。

### フロントエンド

- バックエンドの戦闘画面待機50秒を許容できるよう、指令の既定タイムアウトを90秒へ変更した。
- 専用Chromeから `10 ev++` を選択して開始し、グループごとの進行、「17件の命令を完了しました」の表示を確認した。

### プロジェクト共通

- 専用Chromeの物理矩形 `(0, 0, 300, 1500)` とLDPlayerの物理矩形 `(319, 207, 1962, 1115)` を測定し、19ピクセルの間隔があり重ならないことを確認した。
- ev++の1〜3 wave・全17命令をPythonハンドラーから連続実行し、続いて専用Chromeのアプリ画面からも連続実行した。いずれもゲームのRESULT画面へ進んだ。
- ユーザー指定により、この個人用ツールの対応範囲をこのPCのプライマリ画面とし、セカンダリ画面の表示倍率・座標検証をR19の対象外とした。
- `documents/design/r19-environment-observations.md`へ実測値と操作結果を記録し、ロードマップのR19を完了へ更新した。

# R33 実装ログ — サンプラー専用バックエンド

- 実施日: 2026-09-27
- 対象: R33「専用FastAPI・起動入口・Chrome・SSE生存監視と画像API」
- 状態: 完了

## 実施内容

### バックエンド

- プレイヤーと独立したFastAPI、認証セッション、ポート8010、Chromeプロファイル、起動入口を追加した。
- Chrome終了を監視し、SSE切断後は5秒の再接続猶予を置いて終了する。終了時は新規要求を拒否し、進行中の保存完了を待って元画像を破棄する。
- PNGの受け取りをファイル選択・ドロップ・クリップボードで共用できるバイナリAPIにした。12 MiBと1200万画素の制限、形式・デコード・レイアウト検証を設けた。
- 元画像プレビュー、9候補、既存参照画像、シナリオ内キャラクター一覧、登録・破棄APIを追加した。元画像はメモリだけに保持し、保存後・破棄時・終了時に消去する。
- 登録時は候補とシナリオ内の名前を再検証し、共通の参照保存処理でPNGとmanifestを更新する。manifest更新失敗時はPNGを取り消す。
- 認証、上限、名前の正規化、確認後の保存と元画像破棄をAPIテストで確認した。

# R08 実装ログ — SSEイベント配信と生存監視

- 実施日: 2026-09-20
- 対象: R08「SSEイベント配信と生存監視を実装する」
- 状態: 完了

## 実施内容

### フロントエンド

- Fetch APIのレスポンスストリームからSSEを読み取るクライアントを追加した。
- 接続状態を`connecting`、`active`、`inactive`で通知するようにした。
- 通常イベントまたはハートビートから10秒間無通信の場合に不活性化する監視を追加した。
- HTTPエラー、ストリームの明示的な終了、読み取りエラー、JSON解析エラーでは即座に不活性化するようにした。
- 不活性化時にストリームを中断し、自動再接続しない動作を実装した。
- `sessionId`と`eventId`の組み合わせで重複イベントを破棄するようにした。
- SSE解析、明示終了、無通信タイムアウト、重複排除を検証する3件の単体テストを追加した。

### バックエンド

- `GET /api/events`のSSEエンドポイントと、ライブイベントを接続中クライアントへ配信するイベントブローカーを追加した。
- 起動ごとのUUID v4セッションIDと、1から単調増加するイベントIDを実装した。
- 指令の受付、開始、完了、失敗、取消と実行状態変更をキューから発行するようにした。
- 通常イベントのSSE `id`とJSON `eventId`、SSE `event`とJSON `type`を一致させた。
- 3秒間隔で、イベントIDを持たないハートビートを配信するようにした。
- 通常イベントの形式、ハートビート形式、キューからのイベント発行を検証する3件の単体テストを追加した。

### プロジェクト共通

- 配信方式、切断判定、再接続禁止、重複排除を`documents/design/sse-events-and-liveness.md`へ記録した。
- `documents/roadmap.md`のR08を完了へ更新した。

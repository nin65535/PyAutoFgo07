## 実施内容

### バックエンド

- `GET /api/scenarios`で管理フォルダー直下の操作手順一覧を返すAPIを実装した。
- `GET /api/scenarios/{scenario_id}`で選択したJSONのメタデータと内容を返すAPIを実装した。
- ファイル名をURL-safe Base64化した不透明なIDを採用し、絶対パスや相対パスをAPI入力にしない構成にした。
- IDの正規化、拡張子、解決後の親フォルダーを検証し、管理フォルダー外の読み取りを防止した。
- 一覧を表示名の大文字小文字を区別しない昇順、同値時はID昇順で安定して並べるようにした。
- 存在しないID、読み取り失敗、不正JSONを`SCENARIO_NOT_FOUND`、`SCENARIO_READ_FAILED`、`SCENARIO_INVALID_JSON`として区別した。
- 管理フォルダーを`AUTOFGO_SCENARIO_DIRECTORY`で上書きできるようにした。

### フロントエンド

- R03では変更していない。操作手順スキーマと命令の意味検証は、設計どおり後続のフロントエンド実装で行う。

### プロジェクト共通

# R28 実装ログ — 攻撃命令へのカード認識・選択の統合

- 実施日: 2026-09-27
- 対象: R28「攻撃命令の実行経路へ識別・選択を統合する」
- 状態: 完了

## 実施内容

### フロントエンド

- 文字列形式のカード優先順位を含む攻撃命令を送る際、シナリオの現在の前衛3名を `frontMembers` に付ける。交代命令後の編成も反映する。
- 前衛名が3名に満たないシナリオでは、カード優先順位を使う命令を検証時に拒否する。

### バックエンド

- `cardSlots` と `frontMembers` を受け取る攻撃命令を実行経路に接続した。
- 攻撃ボタン後にゲーム画面を撮影し、既存の色判定・名前識別・カード選択を実行する。3枚の選択が完了してから順にクリックする。
- 不明・曖昧な名前、色判定の失敗、無効な編成や画面サイズではカードをクリックせず命令を失敗させる。数値形式の宝具命令の動作は維持した。
- 成功経路、交代後の前衛名、認識失敗時のクリック抑止をテストした。

- カード参照画像は既存の承認済み3件のみ。未登録衣装や曖昧な画像では安全側に失敗する。

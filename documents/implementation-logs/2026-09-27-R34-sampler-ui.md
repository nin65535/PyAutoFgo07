# R34 実装ログ — サンプラー専用画面

- 実施日: 2026-09-27
- 対象: R34「画像入力、カード選択、9候補比較、保存確認」
- 状態: 完了

## 実施内容

### フロントエンド

- 専用Chromeに表示する全画面向け画面を追加した。シナリオ内キャラクター、衣装ID、既存参照のサムネイルを表示する。
- PNGのファイル選択、ドロップ、貼り付け、クリップボードボタンを実装した。
- 元画像に見出しと5枚のカード位置を重ね、カード、5種類のサイズ、9候補を選択できるようにした。選択候補を拡大し、元画像の切り出し矩形を示す。
- 保存前に名前・衣装・候補を表示し、目視確認チェックを必須にした。保存後と破棄時に画面上の元画像・候補を解放する。

### バックエンド

- 専用FastAPIのトップページとスクリプト配信を仮画面から専用画面へ切り替えた。画像の永続保存と破棄は既存R33 APIを使用する。

### プロジェクト共通

- `documents/roadmap.md` のR34を完了にした。

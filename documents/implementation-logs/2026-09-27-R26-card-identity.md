# R26 実装ログ — キャラクター名識別と不明・曖昧判定

- 実施日: 2026-09-27
- 対象: R26「通常攻撃カードのキャラクター名を識別する」
- 状態: 完了

## 実施内容

### バックエンド

- `autofgo.card_identity` に、参照manifestの検証・読込、倍率別テンプレートの事前準備、5枚のキャラクター名識別を実装した。
- MAE上限40、別キャラとの差10を既定に、不明・曖昧を理由付きで返す。採用できない結果にキャラクター名を付けない。
- 確信度の根拠としてスコア・別キャラとの差・全候補・探索倍率と位置を保持する。確率への変換は行わない。
- 判定基準を固定してからNumPyで差分計算を一括処理し、参照テンプレートを再利用するようにした。NumPy 2.5.3を依存定義とconstraintsへ追加した。
- 固定fixtureによる85枚の判定回帰、曖昧判定、境界値、参照入力検証、透過・リサイズ、桁あふれ、Pillow版との照合一致をテストした。

### プロジェクト共通

- `documents/design/r26-card-identity.md` に使用方法、判定・読込・探索の仕様と制約を記録した。
- `documents/verification/2026-09-27-R26-runtime-and-speed.md` と `r26-runtime-scores.json` に全画像再計算と性能測定を保存した。
- 既存の検証用スクリプトと固定fixtureを残し、再現できる形にした。
- `documents/roadmap2.md` のR26を完了へ更新した。

## 検証結果

- 実画像17枚・85カード: 登録済み65枚の正しい名前を確定、未登録衣装20枚を不明と判定。参照画像は既存3枚のまま。
- 全255候補で、従来版の小数4桁スコア・探索位置・倍率と一致。
- 5枚の照合・判定は中央値0.849秒（0.812～0.975秒）。過去実験の中央値8.090秒から短縮。同一プロセスの代表2画像でも約8.7～10.5倍の短縮を確認した。
- バックエンド全テスト124件成功、1件対象外。
- Ruff lint・format check、pip check成功。`git diff --check`成功（未追跡ファイルは対象外）。

## 補足

- 判定テストの一部はサンドボックスの一時ディレクトリ権限制約で失敗した後、権限付き環境で成功した。
- StarletteとAnyIOの既存非推奨警告2件。
- 画像群は限定条件で採取され、探索範囲の調整にも使用済み。未知画像全般の認識率を保証しない。衣装登録状況はアシスタントの目視評価。
- 候補差10は暫定値。曖昧な実画像での妥当性は今後の検証対象。参照数の増加に応じて照合時間も増える。
- 旧アプリは変更していない。攻撃指令への接続はR28で扱う。

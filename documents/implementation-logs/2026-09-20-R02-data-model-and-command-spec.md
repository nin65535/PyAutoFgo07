- 状態: 完了

## 実施内容

### フロントエンド

- `schemaVersion: 1`を必須とする操作手順JSONの構造と上限制約を定義した。
- `skill`、`master_skill`、`attack`、`swap`の文字列文法、引数数、値域および組み合わせ制約を定義した。
- 文字列命令から変換する判別可能なTypeScriptユニオン型とプロパティ名を定義した。
- 接続状態、シナリオ実行状態、個別指令状態を分離し、許可する状態遷移を定義した。
- ポーリング中の一時停止、クリック中の一時停止、通常停止および緊急停止の扱いを定義した。
- SSE切断後は再接続せず、フロントエンドを不活性化する方針を定義した。

### バックエンド

- 型付きコマンドを固定ハンドラーへ対応付け、文字列命令をバックエンドへ送らない境界を定義した。
- コマンドID、イベントIDおよびセッションIDの発行主体、形式、有効範囲を定義した。
- セッションIDをバックエンド起動ごとに発行するUUID v4とし、イベントIDを起動ごとに`1`から始まる単調増加整数とした。
- REST APIの共通要求・成功応答・エラー応答、HTTPステータスコードおよび認証ヘッダーを定義した。
- SSEイベント名、共通エンベロープ、指令イベントの順序、ハートビート形式を定義した。
- ハートビートを3秒間隔、無通信の切断判定を10秒とし、明示的な終了・エラーは即時切断扱いとした。
- エラーコード、検証詳細コード、キャンセル理由およびREST・SSEで共有するエラー形式を定義した。

### プロジェクト共通

- `documents/design/data-model-and-command-spec.md`を共通仕様の正本として作成した。
- `documents/design/basic-design.md`を確定仕様に合わせて更新し、共通仕様書への参照を追加した。

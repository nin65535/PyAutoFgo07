# R16 実装ログ — ログとエラー表示

- 実施日: 2026-09-25
- 対象: R16「ログとエラー表示を実装する」
- 状態: 完了

## 実施内容

### フロントエンド

- 接続状態、JSON選択、指令受付・開始・完了・失敗・破棄、実行状態変更を画面ログへ追加した。
- ログに時刻、重大度、イベント種別、該当する場合は指令IDを表示し、直近200件に制限した。
- 利用者向け日本語メッセージと、折りたたみ式の開発者向けイベント詳細を分離した。
- SSEイベントから安全な表示ログへ変換する単体テストと、画面表示テストを追加した。

### バックエンド

- 許可フィールドだけをJSON Linesで出力するログ設定を追加した。
- 起動、専用Chrome起動、JSON選択、および全実行イベントを記録するようにした。
- ログ保存先、最大サイズ、保存世代数を設定可能にし、サイズローテーションを実装した。
- 構造化フィールドとローテーション、未許可の機密フィールドを出力しないことをテストした。

### プロジェクト共通

- 保存場所、ローテーション、表示の責務分離、機密情報の非記録規則を
  `documents/design/logging-and-error-display.md` に記録した。
- `documents/roadmap.md` のR16を完了へ更新した。

## 補足

- バックエンドログは既定で `.autofgo/logs/autofgo.log` に保存し、2 MB、5世代で
  ローテーションする。
- フロントエンドの画面ログはメモリ内だけに保持し、セッション終了時に破棄する。
- 認証トークン、セッションID、HTTPヘッダー、JSON本文、スクリーンショット、入力値は
  バックエンドログへ記録しない。
- Vite/Vitestはサンドボックス内で子プロセス起動を拒否されたため、権限付き環境で検証した。
- pytestではFastAPI/Starlette依存関係由来の非推奨警告が2件表示されるが、テスト結果には
  影響しない。
- 旧アプリ `C:\2406_autoplay` のファイルには変更を加えていない。

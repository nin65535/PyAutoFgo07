### バックエンド

- 型付き命令を受け付ける`POST /api/commands`を実装した。
- `skill`、`master_skill`、`attack`、`swap`をPydanticの判別可能なユニオンとして定義し、未知のプロパティ、型、値域、組み合わせを再検証するようにした。
- コマンドIDを小文字・ハイフン付きのUUID v7に限定した。
- 命令種別とハンドラーの対応をソースコード上の固定表として定義した。リクエストから関数名、モジュール名、ファイルパスまたはコード断片を受け取らない。
- 新規受付では`202 Accepted`、同一ID・同一内容の再送では`200 OK`と`duplicate: true`を返し、二重受付を防止した。
- 同一ID・異内容の要求を`409 Conflict`および`COMMAND_ID_CONFLICT`で拒否するようにした。
- Pydanticの検証エラーと不正JSONを、仕様に沿った`VALIDATION_ERROR`および`INVALID_JSON`の共通エラー形式へ変換した。
- 4命令の正常系、再送、ID競合、未知命令、未知フィールド、値域、重複値、UUID形式、不正JSON、固定ディスパッチ表を検証するAPIテストを追加した。

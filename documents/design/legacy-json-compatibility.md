# 旧JSON資産の互換性

## 方針

旧アプリのJSONは新アプリへ直接読み込ませない。`scripts/convert-legacy-scenarios.mjs`で
`schemaVersion: 1`を付与した新形式へ変換し、変換結果だけを`scenarios`へ配置する。
変換ツールは旧形式のルート項目が`members`と`commands`だけであることを確認し、未知の項目や
欠落をエラーにする。命令文字列の書き換えや、任意の式を評価する互換処理は行わない。

```powershell
node scripts/convert-legacy-scenarios.mjs C:\2406_autoplay\python\stages scenarios
```

## 検証結果

2026-09-25時点の`C:\2406_autoplay\python\stages`にある全20ファイルを変換した。
変換後の全ファイルを新スキーマと限定文字列パーサーで検証し、310命令すべてが型付き
コマンドへ変換できることを確認した。

| 命令 | 件数 |
| --- | ---: |
| `skill` | 235 |
| `master_skill` | 16 |
| `attack` | 42 |
| `swap` | 17 |
| 合計 | 310 |

初回計測時の313命令から3件減っているのは、その後に旧JSONが編集されたためである。
2026-09-25時点の旧資産を再集計した結果は310件であり、20ファイルの各命令を漏れなく
数えた回帰テストでも同じ結果となるため、現在の資産に合わせて資料を更新した。
命令仕様の追加や手動修正が必要な差異はなかった。

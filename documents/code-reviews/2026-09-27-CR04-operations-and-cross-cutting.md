## 確認できた指摘

### 1. 中: 古いChromeプロファイルロックの同時回収で二重取得できる

- 箇所: `backend/src/autofgo/browser.py:116-150`。同じプロファイルの二重起動防止を説明する `documents/design/chrome-launch.md` と `documents/operations.md:31` に影響する。
- 成立条件: 古い `.autofgo.lock` が残った状態で、同じプロファイルを使う2つの起動プロセスが、異なるAPIポートなどでChrome起動まで進む。両者が古いPIDを読んだ後、片方が古いロックを削除して新しいロックを作る。もう片方は読込時の古いPIDだけを根拠に、新しいロックを削除できる。`release()` もファイルの所有者を確認しない。
- 再現: 共有した代替ロックストアで、1番目の古いPID確認中に2番目の `acquire()` を完了させた。2番目の所有PIDが `222` になった直後、1番目がそのファイルを削除してPID `333` で取得し、両方の `_held` が真になった。2番目の `release()` は1番目のロックまで削除した。実ファイル・Chromeでは未再現。
- 影響: 専用プロファイルの排他保証が崩れ、Chromeの既存プロセスへの引き渡しや終了監視が意図と異なる可能性がある。通常の同一ポートでの二重起動は先にポート競合で止まるため、主に異なるポートで同時起動した場合の問題。
- 修正案: ロックの所有権をOSの排他ロックでプロセス存続中保持し、古いロックの回収と再取得を競合に耐える手順へ変更する。解放時も自分のロックだけを解放する。古いロックを同時回収する2プロセスの回帰テストを追加する。

### 2. 中: サンプラーのSSE再接続が成立しても5秒後に終了し得る

- 箇所: `backend/src/autofgo/sampler_main.py:63-76`、`backend/src/autofgo/sampler_api.py:251-264`。短い切断では終了しないという `documents/design/local-app-lifecycle-pattern.md` の動作に影響する。
- 成立条件: 最後のSSE接続が切れて `disconnected_task` が完了した後、監視ループが `state.connected.clear()` を実行する前に新しいSSE接続が開始する。接続側は `connected.set()` と `disconnected.clear()` を実行するが、監視側が後から `connected.clear()` して現在の接続通知を消す。
- 再現: 実装と同じ `asyncio.Event` の順序を隔離実行し、再接続後に監視側の `clear()` が走ると、接続済みのまま `connected.wait()` がタイムアウトすることを確認した。実ブラウザーの再読み込みでは未再現。
- 影響: ページ再読み込みなどで5秒以内に再接続できても、サンプラーのAPIとChromeが終了し、保存前の作業画像が破棄される。
- 修正案: 再接続通知を監視側で無条件に消さず、現在の接続数または接続世代を確認してから猶予待ちを判定する。切断と再接続が監視ループの処理前後に起きる両順序をテストする。

### 3. 中: 通常起動時に `.env` のポート変更が反映されない

- 箇所: `scripts/start-autofgo.ps1:29-31`、`backend/src/autofgo/config.py:16-20`、`README.md:21`。ポート変更手順は `documents/operations.md:33`。
- 成立条件: READMEの案内に従い `.env` に `AUTOFGO_PORT=8001` を設定し、シェル側には同名の環境変数を設定せず `start-autofgo.cmd` を起動する。PowerShellはPython開始前に `AUTOFGO_PORT=8000` をプロセス環境へ設定し、`AUTOFGO_CHROME_APP_URL` も8000に固定する。Pydantic Settingsではプロセス環境が `.env` より優先される。
- 影響: 8001へ変更したつもりでも8000へ接続する。8000が他アプリで使用中なら、設定による復旧を試しても起動失敗する。運用手順の「起動前のPowerShellで環境変数を指定する」方法は有効。
- 修正案: 起動スクリプトが `.env` のポートを読み取ってから既定値を補うか、通常起動では `.env` のポートを使わないことを明記する。ポートと専用ChromeのURLが一致する回帰確認を加える。

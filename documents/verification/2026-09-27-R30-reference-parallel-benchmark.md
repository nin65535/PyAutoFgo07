# R30 参照画像単位の並列照合の検証

- 実施日: 2026-09-27
- 対象: 通常カード5枚と登録済み参照画像9件の名前照合
- 状態: 案の検証のみ。実装への採用は保留。

## 方法

失敗時に保存した実画面画像2枚を使用し、ゲーム領域を480×270へ縮小した後の照合時間を同じPCで各3回測定した。現在の5枚単位の並列照合と、各カード・各参照画像の45組をタスクに分ける試作を比較した。試作は `.autofgo/bench-reference-parallel.py` に置き、製品コードは変更していない。両画像の全判定・全候補が現在の方式と一致することを確認した。

| 同時実行数と方式 | 画像1の中央値 | 画像2の中央値 |
| --- | ---: | ---: |
| 5スレッド、カード単位（現在） | 0.742秒 | 0.768秒 |
| 5スレッド、参照画像単位 | 0.737秒 | 0.822秒 |
| 9スレッド、参照画像単位 | 0.573秒 | 0.724秒 |
| 12スレッド、参照画像単位 | 0.527秒 | 0.624秒 |
| 18スレッド、参照画像単位 | 0.499秒 | 0.546秒 |

## 判断

参照画像単位の並列化は技術的に可能で、今回の2画像では18スレッドで約0.20～0.27秒速い。一方、45組のタスク管理と同時実行数の増加に対して、攻撃命令全体の体感時間への寄与は小さい見込み。スレッド数の増加によるメモリ使用量や、ゲーム・Chromeを同時に動かした場合の影響は未測定。現時点では5枚単位の並列照合を維持し、実画面でなお待ち時間が問題なら再検討する。

この測定は名前照合のみ。画面待機、撮影、色判定、クリック、ゲーム側の演出時間は含まない。2画像・各3回の測定であり、全環境の性能を保証するものではない。
